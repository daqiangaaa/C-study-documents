# C 语言学习记录

一个中文母语的 C 语言初学者，从零开始刷入门 OJ 的完整记录。

每道题**都是自己先写**——跑不出来、WA 了、编译报错了，再回头找原因。AC 之后归档到 `solutions/`。

> **这里不只放对的代码。**
> 写错的版本、当时踩的坑，全都原样留着，见 [`solutions/_错题本/`](solutions/_错题本)。
> 对同样在学 C 的人来说，知道「为什么会错」比看正确答案有用。

## 仓库结构

```
├─ README.md            ← 你正在看的这个
├─ 用法说明.md            一键上传脚本怎么用
├─ 一键上传.bat           归档当前题解 → 提交 → 推送到远程
│
├─ 格式符对照表.md        %d / %lf / %lld … 和 int / double 的对应关系
├─ 易错点总表.md          踩过的 8 类错，按「被咬次数」排序
├─ 警告翻译表.md          gcc 警告的中文翻译（警告不是红字，但也要清零）
├─ 结论题怎么想.md        博弈 / 构造题的套路（对称、镜像、奇偶、硬搜验证）
│
├─ 比赛3/                 Code::Blocks 工程（当前在做的题写这里）
│   ├─ main.c            每做一题覆盖一次
│   └─ 比赛3.cbp
│
├─ guessgame/            自己写的猜数字小游戏
│   └─ main.c
│
└─ solutions/            归档区，只增不改
    ├─ README.md         「考点 / 当时踩的坑」对照表
    ├─ 01..18_*.c        最早归档的一批 AC 代码
    ├─ 题目名.c           后来 AC 的题，直接按题目名存
    ├─ _错题本/          18 个写错的版本，文件名直接写病因
    └─ _参考/            5 个规范写法，对照着看
```

**为什么要分「比赛3/」和「solutions/」？**
`比赛3/main.c` 是**草稿纸**，每做一题就被覆盖；`solutions/` 是**档案柜**，进去就不动了。
分不开的结果就是——两周后想找某道题的代码，发现已经被下一题覆盖掉了。

## 编译方式

**Code::Blocks 25.03**（自带 MinGW，gcc 14.2.0）。

编译器选项设置成：

```
-finput-charset=UTF-8 -fexec-charset=GBK -Wall -O2
```

⚠️ 那个 **`-O2` 不能省**：`-Wall` 单独开着**抓不到**「变量没初始化」，加上 `-O2` 才会报
`warning: 'cnt' may be used uninitialized [-Wmaybe-uninitialized]`。

或者命令行直接编：

```bat
"C:\CodeBlocks\MinGW\bin\gcc.exe" -Wall -O2 某个文件.c -o 输出.exe
```

⚠️ **源码路径不要用中文。** MinGW 的链接器处理中文路径会直接失败：
`ld.exe: cannot open output file E:\????\_t.exe: No such file or directory`

## 一直复用的两句口诀

> **`\n` 是这一行的句号，写在行尾。**

> **信息后面还要用就存数组，用完就扔就不存。**

> **scanf 认死理，printf 不挑食。**（`double` 的 scanf 要 `%lf`，printf 用 `%f` 就行）

加分项：**声明的那一刻就把初值写上**——`int cnt = 0;` 当一个整体敲，
永远别先写 `int cnt;` 再指望等会儿补。

📄 详细版：[`格式符对照表.md`](格式符对照表.md) · [`易错点总表.md`](易错点总表.md) · [`警告翻译表.md`](警告翻译表.md) · [`结论题怎么想.md`](结论题怎么想.md)

## 提交前 30 秒检查清单

1. 构建窗口最后一行是不是 `0 error(s), 0 warning(s)`？（**警告也要清零**，不能只看红字）
2. 所有计数器 / 累加器都给了初值吗？
3. `scanf` 格式串和变量对得上吗？该 `&` 的都写了吗？
4. `printf` 的 `%d` 数量和参数数量对得上吗？
5. 每一行的 `\n` 都在行尾吗？
6. 题目给的**最小**和**最大**输入，你的程序会怎样？（除法、取模、数组下标是头号杀手）
7. 输出的大小写和标点，和题目要求一字不差吗？
8. **数一下输出几行**——和样例对得上吗？（抓 `return` / `continue` / 循环变量写错这类编译器看不见的错）

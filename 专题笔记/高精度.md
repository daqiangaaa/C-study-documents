## 1. 加法  P1601

```cpp
vector<int> add(const vector<int>& a, const vector<int>& b) {
    vector<int> c;
    int carry = 0, n = max(a.size(), b.size());
    for (int i = 0; i < n || carry; i++) {      // ← || carry 处理最高位进位
        int t = carry;
        if (i < (int)a.size()) t += a[i];       // ← 长度不同也不用手动对齐
        if (i < (int)b.size()) t += b[i];
        c.push_back(t % 10);
        carry = t / 10;
    }
    if (c.empty()) c.push_back(0);              // ← 0 + 0
    return c;
}
```

## 2. 大数 × 大数  P1303

**两步走：先全累加，再统一进位。** 不要边乘边进位。

```cpp
vector<int> mul(const vector<int>& a, const vector<int>& b) {
    vector<int> c(a.size() + b.size(), 0);
    for (int i = 0; i < (int)a.size(); i++)
        for (int j = 0; j < (int)b.size(); j++)
            c[i + j] += a[i] * b[j];            // ← 先累加，这格可以远大于 9

    for (int k = 0; k + 1 < (int)c.size(); k++) {   // ← 再统一进位
        c[k + 1] += c[k] / 10;
        c[k] %= 10;
    }
    while (c.size() > 1 && c.back() == 0) c.pop_back();
    return c;
}
```

为什么不能边算边进：`c[i+j]` 会被多个 `(i,j)` 命中，第一次进位后后面还要往上加，
加进去的就不是"一位数"了。`2222 × 2222` 会输出 `4812161284`（七列 `4 8 12 16 12 8 4` 直接拼起来）。

## 3. 大数 × 单位数（阶乘） P1591

```cpp
// v 已倒序，cnt = 当前位数，初始 v[0]=1, cnt=1
for (int i = 1; i <= x; i++) {
    int carry = 0;
    for (int j = 0; j < cnt; j++) {
        int temp = v[j] * i + carry;
        v[j] = temp % 10;
        carry = temp / 10;
    }
    while (carry) {              // ← 必须 %10 和 /10，可能连进好几位
        v[cnt++] = carry % 10;
        carry /= 10;
    }
}
```

?? 写成 `while(carry){ v[cnt]=carry; cnt++; carry=0; }` 是错的——等于只进一位。
`14! × 15 = 1307674368000`，最高位要进的是 **13**，塞进一格之后全是垃圾。

## 4. 位数估算（开数组前先算）

| 对象 | 位数 | 例 |
|---|---|---|
| 整数 n | `floor(log10(n)) + 1` | |
| n! | `floor(Σ_{k=1..n} log10(k)) + 1` | 1000! = **2568 位** |
| 2^n | `floor(n · log10 2) + 1` | 2^1000 = 302 位 |

浮点有误差，算出 `m` 后开 `m + 10` 格最稳。
`log10(2) ≈ 0.30102999566398120`。

## 5. 踩过的错（错题本里都有原码）

| 错误写法 | 症状 | 正确做法 |
|---|---|---|
| 大数×大数边算边进位 | 输出 `4812161284` | 先累加，再统一进位 |
| `carry=0` 代替 `carry/=10` | 小数据对，n≥15 开始错 | 进位要连进 |
| 数组开 2010 存 1000! | 越界写（UB） | 1000! 要 2568 位，开 2700+ |
| 输出 `for(int i=size(); i>=0; i--)` | 读 `v[size()]` 越界，靠内存恰好是 0 才 AC | 从 `size()-1` 开始 |
| `0+0` 输出空 | | `if (c.empty()) c.push_back(0);` |

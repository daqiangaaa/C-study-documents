# 题解一键上传 · 用法说明

> ⚠️ **这是我自己用的 Windows 小工具，不是仓库的核心内容。**
> 脚本里写死了 `D:\cpp` 这个路径，换台机器要自己改。想直接看题解，回 [README](../README.md)。

---

## 一句话版本

**在 Code::Blocks 里做出一道题之后，双击桌面「题解一键上传」，然后按两次回车。**

---

## 它到底干了什么

脚本分四步，屏幕上会显示 `[1/4] [2/4] [3/4] [4/4]`：

| 步骤 | 做的事 |
|---|---|
| **[1/4] 归档当前题解** | 自动找出 `D:\cpp` 下**最近改动过**的 `.c` / `.cpp`，复制一份到 `solutions\<你输入的名字>.<原扩展名>` |
| **[2/4] 提交** | `git add -A` + `git commit`，把 `D:\cpp` 下**所有**变动打包成一个存档点 |
| **[3/4] 推 Gitee** | `git push`（失败会自动 `pull --allow-unrelated-histories` 再试一次） |
| **[4/4] 推 GitHub** | 如果配了 `github` 远程，就顺手也推一份（会读系统代理设置） |

**关键：第 2 步的 `git add -A` 管的是整个 `D:\cpp` 文件夹**，不只是那道题。
所以你手动放进 `solutions\` 的文件、改过的 `.md` 笔记，全都会一起传上去。

---

## 两次回车提示

```
[1/4] 题目名 (直接回车 = 不归档):
[2/4] 这次干了啥 (回车 = 自动写日期):
```

- 想归档 → 输入**题目名**（**不要带扩展名**，脚本会自动补；写了 `.cpp` 会变成 `名字.cpp.cpp`）
- 不想归档 → **直接回车**
- 说明懒得想 → **直接回车**，自动写成 `更新 2026/10/25 周日`

> 赶时间的话两次都直接回车，一样能传上去。

## 日常流程

```
1. Code::Blocks 里做题（工程 D:\cpp\比赛4，源文件 main.cpp）
2. F9 编译 → 提交 OJ → AC（Accepted）
3. 双击桌面「题解一键上传」
4. 题目名 → 输入，回车
5. 说明   → 回车
6. 看到「全部完成!」就完事了
```

## 文件都在哪

```
D:\cpp\
├── 比赛4\                ← Code::Blocks 练习工程（.gitignore 里，不进版本库）
│   └── main.cpp           ← 每天在这里写代码（每题都覆盖它）
├── solutions\            ← 题解归档区（进来就不动）
│   ├── README.md          ← 每道题的「考点 / 踩过的坑」对照表
│   ├── 01..18_*.c         ← 最早归档的一批
│   ├── 题目名.c / .cpp     ← 后来 AC 的，直接按题目名存
│   ├── _错题本\           ← 当时写错的原版（一个字没改）
│   └── _参考\             ← 同一题的另一种写法（AI 给的对照版）
├── guessgame\            ← 早期自己写的猜数字小游戏
└── tools\                ← 就是本文件所在目录
    ├── 一键上传.bat
    ├── 查警告.bat / .ps1
    └── 用法说明.md        ← 本文件
```

**`main.cpp` 是被覆盖的那个，`solutions\` 是留下来不动的那个。**

## 几个常见情况

**Q：屏幕显示「没找到任何 .c / .cpp 文件」？**
A：说明 `D:\cpp` 下没有源文件，或者全被排除了。正常做一题再试。

**Q：第一次运行弹窗要账号密码？**
A：用户名填 Gitee 用户名，密码填 Gitee 登录密码。开了两步验证的话，去 Gitee →「设置」→「私人令牌」生成一个，拿它当密码。

**Q：提示推送失败怎么办？**
A：脚本会自己重试一次。**记住：已经传成功的那些内容永远不会丢**，失败了重来一次就行。

**Q：传错了 / 想撤销？**
A：不用慌，把文件改对再双击一次脚本。git 会老老实实记录每一次变化，旧版本一直都在。

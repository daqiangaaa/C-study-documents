| `十进制转二进制并交换.c` | 把一个 32 位二进制数的**高 16 位与低 16 位交换**（样例 `1314520` → `249036820`）| **一行就够：`(n >> 16) \| (n << 16)`**。`>> 16` 把高半挪下来（右边挤出去的丢掉、左边补 0），`<< 16` 把低半挪上去（高半被挤掉），`\|` 把两块**不重叠**的 1 拼起来。**这题真正考的是类型**：范围写的是 `n <= 2^31`（不是 `2^31 - 1`），而 `int` 最大只到 `2147483647` ⇒ `n` 必须 **`unsigned int` + `%u`** | **答案也会超过 `2^31`**：`n = 65535` 的答案是 `4294901760`，用 `int` 存会打出 **`-65536`**（`0xFFFF0000` 最高位是 1，`int` 把它当符号位）⇒ 输入输出**都必须 `%u`**。书上常见的 `((n >> 16) & 0xFFFF) \| ((n & 0xFFFF) << 16)` 本题**不需要**那两个 `& 0xFFFF`（`unsigned` 右移补 0、左移高半直接丢），加了也不出错。我按「拆成 32 个 bit 再交换」写的另一版，与一行版在 **200011 个数**（0~200000 全跑 + 10 个边界）上**逐位一致、0 处不同**，而且只有 32 步、**根本不会超时** —— 这题不是效率问题，是「没必要」 |

## 三个一直复用的口诀

- **`\n` 是这一行的句号，写在行尾。**
- **信息后面还要用就存数组，用完就扔就不存。**
- **循环体里必须有东西能让「条件看的那个变量」变假。** 写循环先答两问：① 条件看的是哪个变量？② 循环体里改了**那个变量**吗？答不上第二个 = 死循环（编译器一个字都不会警告）。同一个错已经栽过**四次**：内层循环复用外层的 `i`、`k/=10;` 掉到花括号外面、`while(a[i]=='K'){ cntk++; }`、**把 `if` 打成 `while` 写成了 `while(s[i]=='a'){ judge++; }`** —— 最后这个最阴：循环体里明明「有东西在变」（`judge++`），变的却不是条件看的那个。 **死循环第四张脸**：`while(scanf("lld",&a)!=EOF)` —— 循环体一个字都没错，错在**以为 `scanf` 只会返回 `1` 或 `EOF`**（它还能返回 `0`）。 **还有一条最容易漏的**：「每一组 / 每一次都要重新数」的变量（`len` / `cnt` / `sum` / `k`），**连声明一起搬进那一层循环的花括号里面**。
- 加分项：声明的那一刻就把初值写上（`int cnt = 0;` 当一个整体敲），别先写 `int cnt;` 再指望等会儿补。

## 提交前 30 秒检查清单

1. 构建窗口最后一行是不是 `0 error(s), 0 warning(s)`？（**警告也要清零**，不能只看红字）
2. 所有计数器/累加器都给了初值吗？
3. `scanf` 格式串和变量对得上吗？该 `&` 的都写了吗？
4. `printf` 的 `%d` 数量和参数数量对得上吗？
5. 每一行的 `\n` 都在行尾吗？
6. 题目给的**最小**和**最大**输入，你的程序会怎样？（除法、取模、数组下标是头号杀手）
7. 输出的大小写和标点，和题目要求一字不差吗？
8. **每一层循环的循环体里，都有东西能让循环条件变假吗？**（没有就是死循环——它不报错、不警告，只是永远不结束）

## 题解 · 第二批（后来 AC 的，没编号）

| 文件 | 题目 | 考点 | 注意 |
|---|---|---|---|
| `大象喝水.c` | 桶高 h、半径 r，一桶装多少水（π≈3.14），喝够 20 升要几桶 | 用整数 `314` 代替 π 避开浮点；`sum=2000000/v; if(2000000%v!=0) sum++;` 向上取整 | 输入顺序是**先 h 后 r** |
| `买文具.c` | a 元 b 角，每件文具 19 角，最多买几件 | 先换算单位 `a = a*10;` 再 `sum = (a+b)/19;` | 输出末尾没有 `\n`，最好补上 |
| `闰年判断.c` | 输入年份，闰年输出 1 否则 0 | `if(n%100==0){ if(n%400==0) judge=1; } else if(n%4==0) judge=1;` | 世纪年必须**先判 100 再判 400**，否则 1900 会被误判 |
| `数的性质.c` | 输入 n，输出 4 个 0/1：是否「偶数且 4<n≤12」/ 至少满足一个 / 恰好满足一个 / 都不满足 | 手工维护 a、b、c、d 四个标志位 | 区间是**开左闭右** `n > 4 && n <= 12` |

| `小鱼游泳的时间.c` | 开始 a 时 b 分、结束 c 时 d 分，求游泳时长 | 全部化成分钟再相减：`e = (c*60+d) - (a*60+b); printf("%d %d", e/60, e%60);` | 没处理跨天（结束时刻早于开始时） |
| `三角形面积.c` | 三边长求面积，保留 1 位小数 | 海伦公式 `p=(a+b+c)/2; area=sqrt(p*(p-a)*(p-b)*(p-c));` | 没判三边能否构成三角形；`sqrt` 要 `#include <math.h>` |
| `摸球的概率.c` | t 组，每组 a 个白球 b 个红球，取两个球是一白一红的概率 | `2ab / (n(n-1))`，欧几里得 gcd 约分；分母为 1 只输出整数 | 分子为 0 直接输出 `0` 并 `continue`（这样 `0 0` 也不会除零） |
| `两面包夹芝士.c` | 多组输入，每行 a b，输出 `min((a+b)/3, a, b)` | 读到 EOF：`while(scanf("%lld%lld",&a,&b)==2)` | 要用 `long long`；别只跟 a 取小，**还要跟 b 取小** |

| `肥胖问题.c` | 洛谷 P5714：算 BMI，<18.5 输出 `Underweight`，<24 输出 `Normal`，否则先输出 BMI 再输出 `Overweight` | `a = (m/h)/h;` + 多分支 | BMI 用 `%g`（六位**有效数字**，不是六位小数） |
| `质数.c` | 读到非正数或 EOF 为止，输出 `编号: yes` / `编号: no` | `for(i=2; i*i<=a; i++)` 试除到平方根 + `isprime` 标志位 | 题目**规定 1 和 2 都不算质数**（和数学课本不一样）；冒号后有空格；编号是**第几个问题**，不是输入的那个数 |
| `kole.c` | 读一个实数 a 和一个整数 n，输出 `a/n`（3 位小数）和 `n*2` | —— | 只有 9 行，两行输出互不相关，像是随手练习，不是正式题解 |
| `严格递增序列.c` | t 组，每组给 n 个数和一个 a，每次花 1 点能量给某个数加 a，求变成严格递增的最小能量 | 一边读一边把当前数顶到「刚超过前一个」：`if(b<=c){ step=(c-b)/a+1; cnt+=step; b+=step*a; }` | 要**严格**递增（相等也不行，判断必须是 `<=`）；`cnt` 和 `c` 每组开头要清零；「一个个加」的写法会超时 |

## 两个一直复用的口诀

- **`\n` 是这一行的句号，写在行尾。**
- **信息后面还要用就存数组，用完就扔就不存。**
- 加分项：声明的那一刻就把初值写上（`int cnt = 0;` 当一个整体敲），别先写 `int cnt;` 再指望等会儿补。

## 提交前 30 秒检查清单

1. 构建窗口最后一行是不是 `0 error(s), 0 warning(s)`？（**警告也要清零**，不能只看红字）
2. 所有计数器/累加器都给了初值吗？
3. `scanf` 格式串和变量对得上吗？该 `&` 的都写了吗？
4. `printf` 的 `%d` 数量和参数数量对得上吗？
5. 每一行的 `\n` 都在行尾吗？
6. 题目给的**最小**和**最大**输入，你的程序会怎样？（除法、取模、数组下标是头号杀手）
7. 输出的大小写和标点，和题目要求一字不差吗？

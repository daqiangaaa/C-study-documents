## `_错题本/`

**故意保留当时写错的原版**，一个字没改。看代码想起自己错在哪，比看正确答案有用。

| 文件 | 错在哪 |
|---|---|
| `0和5_格式串多了逗号.c` | `scanf("%d,%d", ...)`，输入里根本没有逗号 |
| `0和5_边界与换行.c` | `scanf` 格式串末尾带 `\n`；`0 0` 该输出 -1 却输出 0 |

| `两点距离_类型与取地址.c` | 用 `int` 存实数、`%1f`、`%y1` 少 `&`、`&y1` 写两遍 |
| `病毒数字_缺换行与硬编码.c` | 没有行尾 `\n`，100 直接硬编码 `printf("955")` |
| `病毒数字_漏取地址.c` | `scanf("%d", a)` 漏 `&`；十条并列 `if` |
| `数组求和_sum未初始化.c` | `int sum, mx, mn;` 里 `sum` 没给初值 |
| `桶计数_用变量当数组大小.c` | `int cnt[n] = {0}` → `variable-sized object may not be initialized` |
| `桶计数_拿下标比票数.c` | `if (best_i < cnt[i])`，拿**下标**和**票数**比 |
| `mc光照_内外层共用变量i.c` | 嵌套内层循环复用外层 `i`，把外层计数器吃光，只输出一个结果 |
| `进位题_数组越界与格式.c` | 用变量开数组还带初始化；`printf` 写在循环里 |
| `字符串_cnt未初始化_数长度.c` | `int cnt;` 没初始化（这个坑一共栽过 **4 次**） |
| `字符串_cnt未初始化_数n.c` | 同上，第四次 |
| `CET6_漏取地址与小写输出.c` | `scanf("%d", n)` 漏 `&`；输出小写 `Yes` |
| `桶计数_只打印计数没有众数.c` | 只统计了每个数出现几次，没找众数；读了 n 却固定循环 10 次 |
| `质数_控制流位置错误.c` | `return 0;` 写在 `while` 里 → 第一个数就让程序整个退出；`continue` 写在 `for` 里管不到外层循环 |

## 两个一直复用的口诀

- **`\n` 是这一行的句号，写在行尾。**
- **信息后面还要用就存数组，用完就扔就不存。**
- 加分项：声明的那一刻就把初值写上（`int cnt = 0;` 当一个整体敲），别先写 `int cnt;` 再指望等会儿补。

## 提交前 30 秒检查清单

1. 构建窗口最后一行是不是 `0 error(s), 0 warning(s)`？（**警告也要清零**，不能只看红字）
2. 所有计数器/累加器都给了初值吗？
3. `scanf` 格式串和变量对得上吗？该 `&` 的都写了吗？
4. `printf` 的 `%d` 数量和参数数量对得上吗？
5. 每一行的 `\n` 都在行尾吗？
6. 题目给的**最小**和**最大**输入，你的程序会怎样？（除法、取模、数组下标是头号杀手）
7. 输出的大小写和标点，和题目要求一字不差吗？

## 三个一直复用的口诀

- **`\n` 是这一行的句号，写在行尾。**
- **信息后面还要用就存数组，用完就扔就不存。**
- **循环体里必须有东西能让「条件看的那个变量」变假。** 写循环先答两问：① 条件看的是哪个变量？② 循环体里改了**那个变量**吗？答不上第二个 = 死循环（编译器一个字都不会警告）。同一个错已经栽过**四次**：内层循环复用外层的 `i`、`k/=10;` 掉到花括号外面、`while(a[i]=='K'){ cntk++; }`、**把 `if` 打成 `while` 写成了 `while(s[i]=='a'){ judge++; }`** —— 最后这个最阴：循环体里明明「有东西在变」（`judge++`），变的却不是条件看的那个。 **死循环第四张脸**：`while(scanf("lld",&a)!=EOF)` —— 循环体一个字都没错，错在**以为 `scanf` 只会返回 `1` 或 `EOF`**（它还能返回 `0`）。 **还有一条最容易漏的**：「每一组 / 每一次都要重新数」的变量（`len` / `cnt` / `sum` / `k`），**连声明一起搬进那一层循环的花括号里面**。
- 加分项：声明的那一刻就把初值写上（`int cnt = 0;` 当一个整体敲），别先写 `int cnt;` 再指望等会儿补。
